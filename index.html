Bachelor's thesis · Web application

Patterna

A web application that generates optimal sequences of patterns. It measures how similar pattern descriptions are (TF-IDF or Universal Sentence Encoder) and then uses a Markov Decision Process with configurable rewards to build a path from a start pattern to a goal pattern.

  • Similarity matrix, statistics and an interactive force-directed graph of pattern relationships
  • Forced start and goal, reference bonus and sentiment-based reward adjustments
  • Drag and drop reordering, export to TXT, PDF, CSV, PNG or ZIP
  • Slovak and English interface, dark mode, deployed on Vercel
